## Sobre o Sinergi Conversor

O **Sinergi Conversor** é uma aplicação para Windows desenvolvida para conversão e processamento de arquivos utilizados em processos de integração de dados.

A distribuição oficial e as atualizações do aplicativo são mantidas pela **Sinergitech Tecnologia** através deste repositório.

## Download

> ### [➡️ Clique aqui para baixar a versão mais recente](https://github.com/sinergitecnologia/sinergiconversor-updates/releases/latest)

Na página da versão, localize **Assets** e baixe:

`Sinergi_Conversor_Setup_vX.X.X.exe`

Depois, execute o arquivo para iniciar a instalação.

## Instalação

1. Acesse o botão de download acima.
2. Baixe o instalador `.exe` disponível em **Assets**.
3. Execute o instalador do Sinergi Conversor.
4. Conclua as etapas apresentadas pelo Windows.
5. Abra **Sinergi Conversor** pelo menu Iniciar ou pelo atalho criado durante a instalação.

## Atualização automática

O Sinergi Conversor possui um mecanismo integrado de atualização.

Quando uma versão superior à instalada estiver disponível no canal oficial:

1. o programa informa que existe uma nova versão;
2. o usuário decide se deseja atualizar;
3. o instalador é baixado pelo canal oficial da Sinergitech Tecnologia;
4. o download é validado antes da instalação;
5. o instalador da nova versão é iniciado.

A partir da linha **v1.0.10/v1.0.11**, o atualizador utiliza uma pasta dedicada em `LocalAppData`, arquivos temporários exclusivos e proteção contra conflitos com instaladores anteriores.
