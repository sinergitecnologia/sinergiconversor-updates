# Sinergi Conversor

**Conversão e processamento de arquivos para integração de dados, com atualização automática para Windows.**

> **Versão estável atual: v1.0.11**

## ⬇️ Baixar Sinergi Conversor para Windows

### [Baixar a versão mais recente](https://github.com/sinergitecnologia/sinergiconversor-updates/releases/latest)

Na página acima, em **Assets**, baixe o arquivo `Sinergi_Conversor_Setup_vX.X.X.exe` e execute o instalador.

## Instalação

1. Baixe o instalador da versão mais recente.
2. Execute `Sinergi_Conversor_Setup_vX.X.X.exe`.
3. Conclua a instalação normalmente.
4. Abra o **Sinergi Conversor** pelo Windows.

## Atualizações automáticas

O Sinergi Conversor verifica se existe uma versão mais recente publicada no canal oficial da Sinergitech Tecnologia.

Quando uma atualização estiver disponível, o programa informa a nova versão e permite iniciar o download e a instalação. O usuário continua no controle e decide quando deseja atualizar.

## Versão atual

**Sinergi Conversor v1.0.11**

Principais melhorias da linha atual:

- notificação de novas versões;
- atualização pelo canal oficial da Sinergitech Tecnologia;
- download de atualização em pasta dedicada do aplicativo;
- proteção contra conflito com instaladores temporários em execução;
- validação do download antes da instalação;
- correção da verificação para não oferecer novamente a versão já instalada.

## Requisitos

- Microsoft Windows;
- acesso à internet para verificar e baixar atualizações;
- permissões do Windows necessárias para instalação do aplicativo.
